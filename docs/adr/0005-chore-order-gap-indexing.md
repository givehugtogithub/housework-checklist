# 家事順序改用間隔式整數，拖曳只寫入被搬動的那一列

家事清單的順序原本完全隱性（本地是陣列插入順序，Supabase 是依 `id` 遞增）。現在要讓使用者拖曳調整順序，且順序需要跨 Sean/Vera 同步，因此 `chores` 資料表需要新增一個明確的排序欄位。若每次拖曳都重新編號整個清單，一次操作要寫入多筆資料；這會破壞 [ADR-0004](./0004-supabase-sync-fire-and-forget.md) 訂下的「fire-and-forget、不重試」簡單同步模式——任何一筆沒寫成功，清單順序就可能不一致。因此改用間隔式整數（例如新項目間隔 1000：1000, 2000, 3000...）儲存順序，拖曳時只需計算新位置前後兩個值的中間數，寫入被搬動的那一列，其餘列不受影響、也不需要一併寫入。
